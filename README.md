# ioccc-art

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

Each game installs on its own:

| Game | With av | From a release archive |
|---|---|---|
| ASCII Fluid | `av install ascii-fluid` | `./ascii-fluid` |
| Chaos | `av install ioccc-chaos` | `./ioccc-chaos` |

Start one with `av play <name>`.
